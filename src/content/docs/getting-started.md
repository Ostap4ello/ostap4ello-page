## Content collections

Put Markdown or MDX files in `src/content/docs` or `src/content/misc`. Nested folders become nested URLs automatically.

```text
src/content/docs/guides/first-note.md
→ /docs/guides/first-note
```

## Frontmatter

Each page needs a `title`. A `description`, `date`, and `tags` are optional.
